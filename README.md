# **Task Manager**

A simple and clean task manager web app built with **HTML, CSS, and JavaScript**. It lets you create, organize, and manage tasks easily — all saved in your browser with **localStorage**.

---

## **Features**

* Add tasks with name, due date, and category
* Mark tasks as completed
* Delete tasks
* Filter by categories (Inbox, Work, School, Personal)
* Views: Today, Upcoming, Completed
* Search and sort tasks
* Shows total, completed, and pending task stats
* Fully responsive for mobile and desktop

---

## **How to Use**

1. Open **index.html** in your browser
2. Add tasks using the + button
3. Click a task circle to complete it
4. Use sidebar and filters to organize your tasks

---
